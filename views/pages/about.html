About {{siteName}}

The problem: campus events are announced on posters, WhatsApp groups and notice boards. Students miss them, popular events overflow, and organisers have no idea how many people will turn up.

The idea: {{siteName}} puts every event in one place. Students book seats online in seconds, organisers see bookings live, and seat limits stop events from overflowing.

The assistant: an AI help desk answers questions about events, booking, payments and error messages using only the site's own data. If it doesn't know the answer, it opens a support ticket instead of guessing.

How it's built

  • Backend: Node.js and Express with a REST API and proper HTTP status codes.
  • PostgreSQL: events, bookings, FAQs, error codes and support tickets.
  • MongoDB: chat logs and thumbs up/down feedback.
  • Claude API: the assistant, with keyword-matching fallback.
  • Open-Meteo API: event-day weather, with a 3-second time limit and fallback.
  • Monitoring: request logs and a live health page.
